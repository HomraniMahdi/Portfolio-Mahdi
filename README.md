# Portfolio – Mahdi Homrani

Portfolio personnel bilingue (FR / EN) de **Mahdi Homrani**, Ingénieur Full Stack Java / Angular.

Personal bilingual portfolio (FR / EN) of **Mahdi Homrani**, Full Stack Engineer Java / Angular.

## Contenu

- **À propos** : profil, services et stack technique
- **Parcours** : expérience (Orange, ACTIA), formation et compétences
- **Projets** : OTB, Diag Cloud et projets personnels, avec aperçu des images en grand
- **Contact** : email et WhatsApp
- CV téléchargeable en français et en anglais

## Structure

```
index.html                 Page unique (contenu français par défaut)
assets/css/style.css       Styles
assets/js/script.js        Navigation, filtres des projets, aperçu des images
assets/js/i18n.js          Traductions anglaises et sélecteur de langue
assets/images/             Images (projets en WebP)
CV_Homrani_Mahdi.pdf       CV en français
CV_Homrani_Mahdi_AN.pdf    CV en anglais
```

## Lancer en local

Site statique sans dépendance : ouvrir `index.html` dans un navigateur.

## Modifier les textes

- Français : directement dans `index.html`.
- Anglais : dans `assets/js/i18n.js`, via la clé `data-i18n` de l'élément.
